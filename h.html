CSS Selectors

Element Selector

Matches elements by their HTML
tag name(e.g., p, h1, div).

Class selector

Matches elements that
have a specific class attribute.
You can reuse classes
on multiple elements.(e.g.,.f1,f2)

ID Selector

Matches a unique element
with a specific id attribute.
An ID should only be
used once per page.(eg:#f3)

Universal Selector

Matches every single element on the page. Frequently used for global resets (like stripping margins).(eg:*)

Group Selector

Matches the selected elements
on the web page.
It allow user match a particular
selectd elemets.(eg:h1,.f1,#f3)
